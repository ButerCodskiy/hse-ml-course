# Домашнее задание 1: Линейная регрессия, обучение по батчам и валидация

## Описание
Практическое исследование внутренней механики обучения линейной регрессии, влияния масштабирования признаков на градиентную оптимизацию, критериев досрочной остановки и выборочной изменчивости метрик при валидации на конечных выборках.

## Стек технологий
- **Язык:** Python 3.12
- **Библиотеки:** NumPy, Pandas, Scikit-learn, Matplotlib

## Основные разделы и результаты
1. **A. Обучение по батчам и эпохи:**
   - Реализация стохастического градиентного спуска LinearRegressionSGD со схемой random reshuffling без повторений внутри эпохи.
   - Сравнение с аналитическим решением нормальных уравнений МНК (
p.linalg.lstsq) и SGDRegressor из scikit-learn.
2. **B. Масштаб признаков:**
   - Анализ инвариантности прогнозов МНК к обратимым аффинным преобразованиям признакового пространства.
   - Исследование расходимости градиентного спуска при сильной анизотропии дисперсий признаков и постоянном темпе обучения.
   - Улучшение обусловленности матрицы Гессе целевой функции с помощью стандартизации (StandardScaler).
3. **C. Размер батча и критерии остановки:**
   - Сравнение сходимости full-batch (=640$), mini-batch (=32$) и стохастического градиентного спуска (=1$).
   - Анализ ложного раннего останова при заниженном шаге обучения ($\eta$).
   - Сравнение критериев малого изменения функции потерь $\Delta R$ и длины шага весов $\Delta \theta$ с объективным критерием нормы градиента $\lVert \nabla R \rVert_2$.
4. **D. Случайность оценки качества (Монте-Карло):**
   - Анализ выборочной дисперсии RMSE на независимых контрольных выборках различного объема ( \in \{20, 50, 200, 1000\}$).
   - Демонстрация центральной предельной теоремы ( \propto 1/\sqrt{m}$).
   - Парный сравнительный эксперимент: исследование вероятности инверсии порядка близких моделей на малых выборках при слабом сигнале признака.
5. **E. Итоговая диагностика:**
   - Дизайн контролируемых экспериментов (*ceteris paribus*) для изоляции источников стохастичности: оптимизатор, обучающая выборка, оценочная выборка.
